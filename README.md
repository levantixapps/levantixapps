# Levantix Apps

تطبيقات عربية مجانية، بسيطة ونافعة في الحياة اليومية. تعمل على الجوال والحاسوب، وبدون إنترنت، وبلا إعلانات.

## 📱 تطبيقاتنا

### يومي — تنظيم الوقت
خطّط صباحًا، وتابع جدولك، وراجع إنجازك مساءً، مع أوقات الصلاة والورد اليومي.
حسابات للعائلة والفرق، ومتابعة المعاملات بين الأقسام.

[افتح التطبيق](https://levantixapps.github.io/yawmi/) · [طريقة التثبيت](https://levantixapps.github.io/#install) · [دليل الاستخدام](https://levantixapps.github.io/yawmi/guide.html)

## 🛠️ التقنيات
تطبيقات ويب قابلة للتثبيت (PWA) · Supabase · إشعارات Web Push · تعمل بدون إنترنت
